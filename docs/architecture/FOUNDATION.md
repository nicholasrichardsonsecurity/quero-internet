# Fundação Técnica — Quero Internet

## Arquitetura inicial
O MVP começa como monólito modular TypeScript, com API NestJS, Web Next.js, Worker assíncrono, PostgreSQL, Redis e object storage compatível com S3.

## Princípios
- Multiempresa desde a fundação.
- Autorização no backend.
- Domínio desacoplado de IXC, SGP e fornecedores externos.
- Operações externas idempotentes e reconciliáveis.
- Observabilidade e auditoria são conceitos separados.
- Segurança e LGPD entram em cada incremento, não no fim.

## IA e agentes
Agentes auxiliam engenharia, QA e revisão. Nenhum agente decide elegibilidade, pagamento público, suspensão de benefício ou autorização administrativa.
